# Voice Cloning Ethics

Voice cloning can be sensitive. This project is intended for consented and transparent use only.

Rules for public demos:

- Use your own voice or a voice with explicit permission.
- Do not publish reference voice files without consent.
- Do not publish generated speech that impersonates a real person without disclosure.
- Do not use the project for fraud, harassment, spam, or misleading content.
- Add disclosure when generated audio imitates a real person.

Recommended portfolio wording:

> Demo audio was generated from a consented reference sample. The repository does not include private voices, model weights, or generated impersonation audio.
